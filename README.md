# Reflection
 If I were hiring someone and saw this commit history, it would tell me that they make changes in organized steps instead of changing everything at once. The commit messages are clear and explain what was added, which makes the project easier to follow.

How Git Changes My Editing Process

Using Git makes me more careful about making changes to a working script because I can save a working version before making new edits. Before this module, I would usually just change the file directly, but now I would make a commit first so I could return to an earlier version if something broke.

Additional .gitignore Item

One thing I would add to my .gitignore is .venv/. This folder contains a local Python virtual environment with installed packages that are specific to my computer, so it should not be uploaded to GitHub.
